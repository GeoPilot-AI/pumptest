# Citing

If pumptest contributes to published work, please cite the software:

```
Gaddam, J. (2026). pumptest: pumping test analysis in Python (version 0.1.0).
Piezoline Technologies Private Limited. https://github.com/GeoPilot-AI/pumptest
```

There is no archived DOI yet.

Please also cite the original solutions you used (see [Theory](theory.md)) and,
if you use the bundled data, their sources:

- Bakker, M. (2013). Semi-analytic modeling of transient multi-layer flow with
  TTim. *Hydrogeology Journal* 21, 935-943. The TTim documentation (MIT) is
  the source of the digitised Gridley, Sioux Flats and Texas Hill records.
- Yang, X. (2020). *Application and comparison of different methods for aquifer
  test analysis using TTim*. MSc thesis, TU Delft. Source of the AQTESOLV
  parameter values used in validation.
- Leven, C. (2020). *Pumping Test Data from the Hydrogeological Research Site
  "Lauswiesen"*. University of Tuebingen. https://doi.org/10.57754/fdat.hma1z-00r32
  (CC BY-SA 4.0).
- Mueller, S., Leven, C., Dietrich, P., Attinger, S. and Zech, A. (2022). How to
  find aquifer statistics utilizing pumping tests? Two field studies using
  welltestpy. *Groundwater* 60(1), 137-144. https://doi.org/10.1111/gwat.13121.
  Source of the welltestpy estimates used in validation.
