# Citing

If pumptest contributes to published work, please cite the software:

```
Gaddam, J. (2026). pumptest: pumping test analysis in Python (version 0.1.0).
Piezoline Technologies Private Limited. https://github.com/GeoPilot-AI/pumptest
```

There is no archived DOI yet.

Please also cite the original solutions you used (see [Theory](theory.md)) and,
if you use the bundled data, their sources:

- Kruseman, G.P. and de Ridder, N.A. (1994). *Analysis and evaluation of
  pumping test data*, 2nd ed. ILRI Publication 47, Wageningen.
- Bakker, M. (2013). Semi-analytic modeling of transient multi-layer flow with
  TTim. *Hydrogeology Journal* 21, 935-943. The TTim documentation (MIT) is
  the source of the digitised Oude Korendijk, Gridley, Sioux Flats, Texas Hill,
  Dalem and Vennebulten records.
- Yang, X. (2020). *Application and comparison of different methods for aquifer
  test analysis using TTim*. MSc thesis, TU Delft. Source of the AQTESOLV and
  MLU parameter values used in validation.
